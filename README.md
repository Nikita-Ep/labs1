### Текст задачи
Необходимо реализовать метод `public int sumLastNums (int x)`, чтобы он возвращал результат сложения двух последних знаков числа х, предполагая, что знаков в числе не менее двух.
### Алгоритм решения
Выделение последней цифры числа (`x % 10`) и предпоследней цифры  (`(x / 10) % 10`). Затем полученные значения суммируются.

`public int sumLastNums(int x) {`  
    `int a = x % 10;`  
    `int b = (x / 10) % 10;`  
    `return a + b;`  
`}`

## Задача 8 (Делитель)

### Текст задачи

Необходимо реализовать метод `public boolean isDivisor (int a, int b)`, чтобы он возвращал true, если любое из принятых чисел делит другое нацело.

### Алгоритм решения

Вычисление остатков от деления `b % a` и `a % b`. Если хотя бы один из остатков равен 0, то одно число является делителем другого, метод возвращает `true`.

`public boolean isDivisor(int a, int b) {`  
    `int c1 = b % a;`  
    `int c2 = a % b;`  
    `return c1 == 0 || c2 == 0;`  
`}`

## Задача 2 (Безопасное деление)

### Текст задачи

Необходимо реализовать метод `public double safeDiv (int x, int y)`, чтобы он возвращал деление x на y, и при этом гарантировал, что не будет выкинута ошибка деления на 0. При делении на 0 следует вернуть 0.

### Алгоритм решения

До выполнения деления проверяется условие `y == 0`. Если оно истинно, возвращается `0.0`. В противном случае выполняется деление с приведением одного из операндов к типу `double`.

`public double safeDiv(int x, int y) {`  
    `if (y == 0) {`  
        `return 0;`  
    `}`  
    `return (double) x / y;`  
`}`

Необходимо реализовать метод `public String makeDecision (int x, int y)`, чтобы он возвращал строку, которая включает два принятых методом числа и корректно выставленный знак операции сравнения (больше, меньше, или равно).

### Алгоритм решения

Используется условная конструкция `if-else-if`. Сравниваются значения `x` и `y`, и в зависимости от результата конкатенируется строка со знаком `">"`, `"<"` или `"=="`.

`public String makeDecision(int x, int y) {`  
    `if (x > y) {`  
        `return x + ">" + y;`  
    `} else if (x < y) {`  
        `return x + "<" + y;`  
    `} else {`  
        `return x + "==" + y;`  
    `}`  
`}`

### Текст задачи

Необходимо реализовать метод `public boolean sum3 (int x, int y, int z)`, чтобы он возвращал true, если два любых числа (из трех принятых) можно сложить так, чтобы получить третье.

### Алгоритм решения

Проверяются три возможных комбинации сложения пар чисел: `(x + y) == z`, `(x + z) == y` и `(z + y) == x` через логическое «ИЛИ» (`||`).

`public boolean sum3(int x, int y, int z) {`  
    `if (((x + y) == z) || ((x + z) == y) || ((z + y) == x)) {`  
        `return true;`  
    `} else {`  
        `return false;`  
    `}`  
`}`

## Задача 8 (Возраст)

### Текст задачи

Необходимо реализовать метод `public String age (int x)`, возвращающий строку с числом х и правильным склонением слова (год, года, лет).

### Алгоритм решения

Вычисляются остатки от деления на 100 и на 10. Исключаются числа, оканчивающиеся на 11-14 (для них всегда «лет»). Для остальных случаев: если последняя цифра 1 — «год», если от 2 до 4 — «года», иначе — «лет».

`public String age(int x) {`  
    `int lastTwo = x % 100;`  
    `int last = x % 10;`  
  
    `if (lastTwo >= 11 && lastTwo <= 14) {`  
        `return x + " лет";`  
    `}`  
  
    `if (last == 1) {`  
        `return x + " год";`  
    `}`  
  
    `if (last >= 2 && last <= 4) {`  
        `return x + " года";`  
    `}`  
  
    `return x + " лет";`  
`}`

### Алгоритм решения

Строка приводится к нижнему регистру. Оператор `switch` реализует проход: ключевое слово `break` ставится только в самом последнем блоке (`воскресенье`), благодаря чему выводятся все оставшиеся дни недели.

            `System.out.println("вторник");`

            `System.out.println("четверг");`

            `System.out.println("пятница");`

## Задача 2 (Числа наоборот)

### Текст задачи

Необходимо реализовать метод `public String reverseListNums (int x)`, возвращающий строку с числами от x до 0 (включительно).

### Алгоритм решения

Используется цикл `while`, выполняющийся пока `x >= 0`. На каждой итерации текущее значение `x` конкатенируется со строкой-результатом, после чего `x` уменьшается на 1 (`x--`).

`public String reverseListNums(int x) {`  
    `String res = "";`  
    `while (x >= 0) {`  
        `res = res + x + " ";`  
        `x--;`  
    `}`  
    `return res;`  
`}`  

## Задача 4 (Степень числа)

### Текст задачи

Необходимо реализовать метод `public int pow (int x, int y)`, возвращающий результат возведения x в степень y.

### Алгоритм решения

Заводится переменная-аккумулятор со значением 1. В цикле `while (y > 0)` аккумулятор последовательно умножается на основание `x`, а показатель `y` декрементируется.

`public int pow(int x, int y) {`  
    `int res = 1;`  
    `while (y > 0) {`  
        `res = res * x;`  
        `y--;`  
    `}`  
    `return res;`  
`}`

## Задача 6 (Одинаковость)

### Текст задачи

Необходимо реализовать метод `public boolean equalNum (int x)`, возвращающий true, если все знаки числа одинаковы.

### Алгоритм решения

Сохраняется последняя цифра числа (`x % 10`). Затем в цикле `while (x > 9)` число последовательно делится на 10, текущая последняя цифра сравнивается с эталоном. Если обнаружено несовпадение, возвращается `false`.

`public boolean equalNum(int x) {`  
    `int last = x % 10;`  
    `while (x > 9) {`  
        `x = x / 10;`  
        `int cur = x % 10;`  
        `if (last != cur) {`  
            `return false;`  
        `}`  
    `}`  
    `return true;`  
`}`

Необходимо реализовать метод, выводящий на экран треугольник из символов ‘*’ высотой х, где количество символов в ряду совпадает с номером строки.

### Алгоритм решения

Внешний цикл `for` идет от 1 до `x` (строки). На каждой итерации к строке `line` добавляется одна звездочка, и текущее состояние строки с добавлением переноса строки записывается в итоговую переменную

`public String leftTriangle(int x) {`

    `String line = "";`  
  
    `for (int i = 1; i <= x; i++) {`  
        `line = line + "*";`  
        `res = res + line + "\n";`  
    `}`  
  
    `return res;`  
`}`
  

## Задача 10 (Угадайка)

### Текст задачи

Необходимо реализовать метод `public String guessGame(int x)`, генерирующий случайное число от 0 до 9 и запрашивающий у пользователя ввод, пока число не будет угадано. Вывести количество попыток.

### Алгоритм решения

Используется цикл `do-while`. Внутри с помощью вспомогательного метода `readInt` считывается число с проверкой диапазона. Счётчик `attempts` увеличивается на каждой корректной попытке. Цикл завершается, когда число совпадает с рандомным.

`public String guessGame(int x) {`  
    `Random random = new Random();`  
    `int randomnum = random.nextInt(10);`  
    `Scanner scanner = new Scanner(System.in);`  
    `int attempts = 0;`  
    `int userGuess;`  
  
    `do {`  
        `userGuess = readInt(scanner);`  
        `if (userGuess < 0 || userGuess > 9) {`  
            `System.out.println("Число вне диапазона!");`  
            `continue;`  
        `}`  
        `attempts++;`  
        `if (userGuess == randomnum) {`  
            `System.out.println("Угадал!");`  
        `} else {`  
            `System.out.println("не угадал");`  
        `}`  
    `} while (userGuess != randomnum);`  
  
    `return "Количество попыток: " + attempts;`  
`}`

# Задание 4. Массивы

  
## Задача 2 (Поиск последнего значения)

### Текст задачи

Необходимо реализовать метод `public int findLast (int[] arr, int x)`, возвращающий индекс последнего вхождения числа x в массив arr. Если не найдено — -1.

### Алгоритм решения

Цикл `for` осуществляет обход массива в обратном порядке (от `arr.length - 1` до `0`). При первом же совпадении элемента с `x` возвращается текущий индекс. Если цикл завершился, возвращается `-1`.

`public int findLast(int[] arr, int x) {`  
    `for (int i = arr.length - 1; i >= 0; i--) {`  
        `if (arr[i] == x) {`  
            `return i;`  
        `}`  
    `}`  
    `return -1;`  
`}`  

## Задача 4 (Добавление в массив)

### Текст задачи

Необходимо реализовать метод `public int[] add (int[] arr, int x, int pos)`, возвращающий новый массив, в котором в позицию pos вставлено значение x.

### Алгоритм решения

Создается массив размером `arr.length + 1`. В цикле элементы до индекса `pos` копируются один к одному. В ячейку `pos` записывается значение `x`. Элементы после `pos` копируются со смещением индекса из старого массива (`arr[i - 1]`).

`public int[] add(int[] arr, int x, int pos) {`  
    `int[] newArr = new int[arr.length + 1];`  
  
    `for (int i = 0; i < newArr.length; i++) {`  
        `if (i < pos) {`  
            `newArr[i] = arr[i];`  
        `} else if (i == pos) {`  
            `newArr[i] = x;`  
        `} else {`  
            `newArr[i] = arr[i - 1];`  
        `}`  
    `}`  
    `return newArr;`  
`}`  

## Задача 6 (Реверс)

### Текст задачи

Необходимо реализовать метод `public int[] reverse (int[] arr)`.

### Алгоритм решения

Создается новый массив аналогичной длины. Элементы исходного массива перебираются с конца (`arr.length - 1` до `0`) и последовательно записываются в новый массив, начиная с нулевого индекса.

`public int[] reverse(int[] arr) {`  
    `int[] newArr = new int[arr.length];`  
    `int j = 0;`  
    `for (int i = arr.length - 1; i >= 0; i--) {`  
        `newArr[j] = arr[i];`  
        `j++;`  
    `}`  
    `return newArr;`  
`}`  

## Задача 8 (Объединение)

### Текст задачи

Необходимо реализовать метод `public int[] concat (int[] arr1, int[] arr2)`, возвращающий новый массив, содержащий сначала элементы arr1, затем arr2.

### Алгоритм решения

Выделяется память под массив длиной `arr1.length + arr2.length`. Первым циклом `for` копируются элементы из `arr1`. Вторым циклом копируются элементы из `arr2` со смещением индекса на величину `arr1.length`.

`public int[] concat(int[] arr1, int[] arr2) {`  
    `int[] newArr = new int[arr1.length + arr2.length];`  
    `for (int i = 0; i < arr1.length; i++) {`  
        `newArr[i] = arr1[i];`  
    `}`  
    `for (int i = 0; i < arr2.length; i++) {`  
        `newArr[arr1.length + i] = arr2[i];`  
    `}`  
    `return newArr;`  
`}`  

## Задача 10 (Удалить негатив)

### Текст задачи

Необходимо реализовать метод `public int[] deleteNegative (int[] arr)`, возвращающий новый массив без отрицательных элементов.

### Алгоритм решения

Первым проходом по массиву подсчитывается количество неотрицательных элементов (`x >= 0`). Создается массив найденной длины. Вторым проходом элементы, удовлетворяющие условию, копируются в новый массив.

`public int[] deleteNegative(int[] arr) {`  
    `int c = 0;`  
    `for (int x : arr) {`  
        `if (x >= 0) {`  
            `c++;`  
        `}`  
    `}`  
    `int[] newArr = new int[c];`  
    `int ind = 0;`  
    `for (int i = 0; i < arr.length; i++) {`  
        `if (arr[i] >= 0) {`  
            `newArr[ind++] = arr[i];`  
        `}`  
    `}`  
    `return newArr;`  
`}`
